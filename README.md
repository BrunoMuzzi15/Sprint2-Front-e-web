# JOVI Luz Dinâmica

O projeto JOVI Luz Dinâmica foi desenvolvido com o objetivo de apresentar uma proposta de tecnologia voltada para câmeras de smartphones, utilizando o conceito de ajuste inteligente da iluminação. A aplicação apresenta como a tecnologia pode auxiliar o usuário em diferentes condições de iluminação, como ambientes escuros e ambientes com excesso de luz. O projeto foi desenvolvido inicialmente em HTML e CSS nas sprints anteriores e, nesta etapa, foi realizada a migração para React, utilizando componentes funcionais, imports e estrutura de componentes pai e filho. Também foram implementadas funcionalidades utilizando localStorage para armazenamento de dados e recursos matemáticos do JavaScript, como Math.random() para geração de valores aleatórios e Math.round() para arredondamento dos resultados.

As tecnologias utilizadas no projeto são React, JavaScript, HTML5, CSS3, Vite, Node.js, npm, Git, GitHub, localStorage, Math.random() e Math.round(). O React foi utilizado para realizar a migração do protótipo anterior e permitir a criação de uma aplicação baseada em componentes. O Vite foi utilizado para criação e execução do ambiente de desenvolvimento. HTML e CSS foram utilizados na estrutura e estilização da aplicação, mantendo o visual desenvolvido no protótipo das sprints anteriores.

Para executar o projeto em outra máquina, é necessário possuir o Node.js e o npm instalados. Também é recomendado possuir o Git instalado caso o projeto seja clonado diretamente do GitHub. Para obter o projeto, deve-se utilizar o comando "git clone https://github.com/BrunoMuzzi15/Sprint2-Front-e-web.git" e, em seguida, entrar na pasta do projeto utilizando o comando "cd Sprint2-Front-e-web". Depois disso, deve-se instalar as dependências utilizando o comando "npm install". Após a instalação, o projeto pode ser executado utilizando o comando "npm run dev". O Vite irá iniciar o servidor de desenvolvimento e apresentar no terminal um endereço semelhante a "http://localhost:5173/". Esse endereço deve ser acessado pelo navegador para visualizar a aplicação.

A aplicação possui uma página inicial com a apresentação da JOVI Luz Dinâmica, cards informativos sobre diferentes condições de iluminação, apresentação da tecnologia, imagem do smartphone, página de comparação, simulação de ajustes da câmera, página de login e página de contato. Na simulação são utilizados métodos matemáticos do JavaScript, principalmente Math.random() para gerar valores aleatórios e Math.round() para realizar o arredondamento dos resultados. O localStorage também é utilizado para armazenar informações relacionadas às configurações e aos resultados da simulação, permitindo que esses dados sejam recuperados posteriormente no navegador.

A aplicação foi desenvolvida utilizando componentes funcionais do React, organizando diferentes partes da interface em componentes, como cabeçalho, conteúdo principal, cards de benefícios, apresentação da tecnologia, comparação, login, contato e rodapé. A estrutura utiliza a relação entre componente pai e componente filho, permitindo a passagem de informações e funções através de props. Essa organização facilita a manutenção, reutilização e compreensão do código.

O projeto possui uma página de Login para representar a funcionalidade de acesso à aplicação, porém não utiliza uma autenticação real conectada a banco de dados ou servidor. Dessa forma, não é necessário informar usuário ou senha para executar e visualizar o projeto.
